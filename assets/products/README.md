# Fotos de productos

Imágenes del catálogo de `index.html`. Sube aquí estos archivos con estos nombres exactos:

| Archivo          | Tarjeta   |
|------------------|-----------|
| `cervezas.webp`  | Cervezas  |
| `vino.webp`      | Vinos     |
| `pisco.webp`     | Piscos    |
| `bebidas.webp`   | Bebidas   |
| `hielo.webp`     | Hielo     |
| `snacks.webp`    | Snacks    |

Formato recomendado: `.webp`, vertical 3:4 (por ejemplo 768×1024), producto centrado sobre fondo blanco.

Si un archivo no está, la tarjeta muestra el ícono de la categoría.
